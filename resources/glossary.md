# 📖 Glossary

| Term | Meaning |
|------|---------|
| **Cloud computing** | Renting computing resources over the internet instead of owning hardware |
| **IaaS / PaaS / SaaS** | Infrastructure, Platform, Software as a Service: from most to least control for you |
| **Region / Zone** | A geographic area / an isolated location inside a region |
| **Project (Google Cloud)** | A container for your resources, billing and permissions |
| **IAM** | Identity and Access Management: who can do what |
| **Role** | A set of permissions |
| **Least privilege** | Give only the access that is needed and no more |
| **Service account** | An identity for an app or automation, not a person |
| **VM (virtual machine)** | A computer simulated in software, rented from the cloud |
| **Container** | A packaged app with everything it needs to run |
| **Image** | The blueprint a container is created from |
| **Dockerfile** | The recipe for building an image |
| **Cloud Run** | Google Cloud service that runs containers without managing servers |
| **Serverless** | You deploy code; the provider manages the servers |
| **Bucket** | A container for files in object storage |
| **VPC** | Virtual Private Cloud: your private network in the cloud |
| **Firewall rule** | Controls which network traffic is allowed |
| **CI** | Continuous Integration: build and test automatically on every change |
| **CD** | Continuous Delivery/Deployment: release automatically |
| **Pipeline / Workflow** | A defined series of automated steps |
| **IaC** | Infrastructure as Code: define infrastructure in files |
| **Terraform** | A popular IaC tool |
| **State (Terraform)** | A record of what Terraform manages. It can hold sensitive data, so keep it private |
| **Secret** | A password, key or token that must be protected |
| **Audit log** | A record of who did what, and when |
| **Observability** | Understanding a system from its logs, metrics and traces |
| **Agent (AI)** | A system where a model uses tools and instructions to complete tasks |
| **Budget alert** | A notification when cloud spending reaches a threshold |
