# 🎓 Certifications

Certificates help, but projects matter more. Build first, certify second. Always check the official site for current exam details, requirements and prices.

## Google Cloud
| Level | Certification | Good for |
|-------|---------------|----------|
| Beginner | **Cloud Digital Leader** | Understanding cloud concepts and business value |
| Associate | **Associate Cloud Engineer** | Deploying and managing cloud workloads |
| Professional | Cloud Architect, Cloud DevOps Engineer, Cloud Security Engineer and others | Specialised roles after experience |

## Other clouds
- AWS: Cloud Practitioner, Solutions Architect Associate
- Microsoft: Azure Fundamentals (AZ-900)

## How to prepare
1. Do the matching Skills Boost learning path
2. Build a project that uses the same services
3. Take the official sample questions
4. Form a study group in the track channel
