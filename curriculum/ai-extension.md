# Optional Extension: AI on Google Cloud

[← Curriculum overview](README.md)

AI is an optional specialisation, not a replacement for the cloud engineering core. Members should first understand application runtime, networking, identity, deployment, data handling and observability.

## Prerequisites
A working application and basic API integration; safe environment-variable and secret handling; understanding of request/response flows, latency and error handling; awareness of privacy, consent and cost controls.

## Outcomes
Explain the difference between a model API call, retrieval-augmented application and tool-using agent; integrate a model endpoint behind an application API; validate inputs and outputs; handle failures and set limits; evaluate output quality with a small test set; explain privacy, prompt injection, tool permissions, human oversight and inference costs.

## Suggested project
Add one bounded AI-assisted feature to an existing capstone. Keep the non-AI workflow functional. Document model access, data sent, failure handling and usage controls. Use current official documentation for product selection and pricing; do not hard-code a particular model or API into the core curriculum.
