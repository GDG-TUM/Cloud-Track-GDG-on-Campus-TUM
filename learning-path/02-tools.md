# Stage 2: Tools

**Goal:** Get comfortable with the tools every cloud engineer uses daily.

**Matching session:** [week-02-tools-of-the-trade](../weekly-sessions/week-02-tools-of-the-trade/README.md)

## What you will learn
- Linux command line: navigation, files, permissions, pipes
- Git: init, clone, add, commit, branch, merge, pull request
- GitHub workflow: fork, branch, pull request, review
- Docker: images, containers, Dockerfile, volumes, ports

## Hands-on
1. Make your first pull request to the `members` folder.
2. Write a `Dockerfile` for a tiny web app.
3. Build and run it locally, then stop and remove the container.

## Free resources
See [resources](../resources/free-resources.md) for official docs, labs and tutorials.

## ✅ Checkpoint
- Can I create a branch, commit and open a pull request without help?
- Can I explain the difference between an image and a container?
- Can I read a Dockerfile and say what each line does?

If you can answer these, move to the next stage. If not, revisit the topics or ask in the track channel.
