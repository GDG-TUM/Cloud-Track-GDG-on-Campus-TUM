# Stage 3: Build and Deploy

**Goal:** Put an application on the internet and give it data.

**Matching session:** [week-03-compute-and-containers](../weekly-sessions/week-03-compute-and-containers/README.md)

## What you will learn
- Compute options: Compute Engine (virtual machines), Cloud Run (containers)
- Deploying a container to Cloud Run
- Cloud Storage buckets
- Databases: relational (Cloud SQL) vs document (Firestore)
- Networking basics: VPC, subnets, firewall rules, IP addresses

## Hands-on
1. Deploy a container to Cloud Run and open its URL.
2. Store a file in a Cloud Storage bucket.
3. Draw a diagram of your app: user, service, storage, database.
4. **Delete everything** you created when you finish.
