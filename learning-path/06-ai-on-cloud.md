# Stage 6: AI on the Cloud

**Goal:** Build with generative AI and agents on Google Cloud.

**Matching session:** [week-04-agentic-ai-study-jam](../weekly-sessions/week-04-agentic-ai-study-jam/README.md)

## What you will learn
- What an AI agent is: model, tools, instructions, memory
- Agent patterns: single agent, multi-agent, tool use
- Moving from prototype to something production-ready
- Responsible use: privacy, cost, testing, human oversight

## Hands-on
1. Complete the suggested labs in [hackathon prep](../hackathon-prep/README.md).
2. Build a small agent that uses at least one tool.
3. Write 5 sentences on what worked and what surprised you.

## Free resources
See [resources](../resources/free-resources.md) for official docs, labs and tutorials.

## ✅ Checkpoint
- Can I explain what makes an agent different from a plain chatbot?
- What could go wrong if an agent is given too many permissions?
- What would I need to add to make my prototype production-ready?

If you can answer these, move to the next stage. If not, revisit the topics or ask in the track channel.
