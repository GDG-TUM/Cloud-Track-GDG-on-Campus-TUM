# Curriculum Roadmap

[← Back to Cloud Track home](../README.md)

The current programme is a 16-week sequence. The previous October–December 2026 schedule was a cohort-specific pilot plan and is no longer the authoritative curriculum.

See the [16-week curriculum roadmap](../curriculum/roadmap.md) for weekly topics, dependencies and required evidence.

## Cohort scheduling
The Track Lead should publish cohort-specific calendar dates separately from the curriculum. This keeps the learning sequence reusable across semesters and avoids embedding dates that become stale.

## Delivery principles
- Preserve the 16-week learning order unless a documented cohort constraint requires adjustment.
- Do not compress foundational prerequisites without catch-up material.
- Every session must retain a core outcome and a stretch option.
- Verify current cloud pricing, quotas and interfaces before scheduling cloud labs.
- Record changes and announce them to members.
