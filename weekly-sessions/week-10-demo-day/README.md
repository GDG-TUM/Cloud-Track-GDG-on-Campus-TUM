# Week 10: Demo day

**Date:** 14 Dec (draft; confirm time and venue in the track channel)

**Goal:** Show what you built, reflect, and plan the next semester.

## Learning objectives
By the end you should be able to:
- Present a project clearly in 5 minutes
- Give and receive useful feedback
- Decide what comes next

## Before the session
- [ ] Capstone repo with README
- [ ] Live demo or recording ready

## Agenda
1. Welcome (5 min)
2. Team demos: 5 minutes each plus 2 minutes of questions
3. Feedback and recognition (15 min)
4. Retrospective: what worked, what to change (20 min)
5. Planning next semester (10 min)

## Hands-on reference
Demo checklist:
- [ ] Problem and audience in one sentence
- [ ] Live demo or short recording
- [ ] Architecture diagram
- [ ] What you learned
- [ ] What you would do next
- [ ] Resources cleaned up or budget-safe
